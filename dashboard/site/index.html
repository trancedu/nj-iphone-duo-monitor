这些时间与时长意味着什么？

分段规则：同一门店、同一型号配置，中间只要有一次确认无货，就结束当前记录。下一次有货是新记录，即使只相隔一秒，也不合并。超过 2 分钟没有有货观测、又无法确认结束时，单独标记为“观测中断 / 结束未知”。

有货时长（保守） = 本次末次确认有货 − 本次首次确认有货。不使用推断结束时间、不计入后续等待确认无货的时间，也不跨任何已确认无货的间隔。只有一个时间点时显示 0 秒，实际时长未知。采样间隔内的变化仍可能被漏掉，不能保证全程都可购买。

确认无货指不再符合当天至未来三天的自提条件。快照提供该店/配置的状态；历史推断则来自后续覆盖该店和配置、且符合条件库存总数为零的成功查询。错误、超时和未覆盖该店均不等于无货。旧快照已被覆盖，历史证据不全的部分保持未知。

时间来自已保留日志，所有时间为美东时间。1TB / 2TB 仅显示历史，目前不监控。
