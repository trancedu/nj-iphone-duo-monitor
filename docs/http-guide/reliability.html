同一个 key 在 30 分钟内不重复发消息；状态保存到磁盘，重启仍然生效。

这是时间去重，不是“每次重新有货都必发”。同一组合在半小时内短暂消失又回来，也可能被抑制。

独立 watchdog

主监控和故障守护由两个 launchd 任务运行。守护每分钟检查主程序状态、最近完成时间和预定下一轮时间。

进程停止持续约两分钟，或持续查询错误约五分钟，会进入告警。卡住检测还会考虑预定重试时间及额外宽限。同一故障发一次，稳定恢复后再发一次；新故障提醒最多每小时一次。

恢复通知需要至少两次健康检查，并受发送重试窗口约束。Mac 睡眠、关机或无法联网时不能即时发消息。

请求次数的边界

请求何时发生是否计入“每轮 2 次”
GET Apple pickup-message每轮两个区域，合并两个型号是；这是库存请求预算。
POST Telegram sendMessage符合规则的新提醒，或故障/恢复通知否；另一项服务。
浏览器加载商品页及资源有货时自动打开商品页，或你手动访问否；浏览器自身访问。
诊断与手动测试请求排查接口、验证覆盖时否；并非正常轮询的一部分，应单独控制。
