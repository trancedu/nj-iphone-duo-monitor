Request 与 Response 是一对

Mac 主动发出一次 Request（请求），Apple 针对这次请求返回一次 Response（响应）。响应结束后，服务器不会继续给监控推送库存；下一次刷新需要再发一个请求。

这是轮询 polling。接收一个包含 12 家门店的 JSON，不等于又发了 12 次请求。

HTTPS 不是明文广播

连接目标是 www.apple.com:443。域名解析、TCP 与 TLS 由 Python 网络库和系统处理。请求路径、参数和响应正文通过 HTTPS 传输。

Python 的 opener 保存自己的会话 Cookie；它没有读取你浏览器的 Apple ID 登录状态。复用 opener 也不代表始终复用同一条 TCP 连接。

读完六页，你可以自己判断这些问题

  2. 一轮两次请求，为什么能得到几十个“门店 × 型号”结果？
  3. 没有返回、返回无货、返回远期日期，分别意味着什么？
  4. 为什么今天旧记录只覆盖 12 家，修复后可以覆盖 35 家？
