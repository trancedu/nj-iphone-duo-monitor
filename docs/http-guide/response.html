按字段阅读，而不是看到 true 就提醒


这两个状态必须分开。
HTTP 200 表示收到了一次成功响应；pickupDisplay: "unavailable" 则表示这个门店的这个型号当前不可取货。二者同时出现完全正常。


当前代码的筛选顺序
  1. 验证响应中的 location 与请求邮编一致。
  2. 验证预期门店都返回了，每家目标店的两个 SKU 都存在。
  3. 读取 pickupDisplay，并读取 messageTypes.regular.storeSelectionEnabled；两者共同允许取货才继续。
  4. 读取明确的 pickup 日期；若没有 pickup 专用编码，才解析取货文案中的 Today、Tomorrow 或明确日期。
  5. 按美东日期筛选：今天至未来 3 天；同店、同 SKU、同日期 30 分钟内不重复提醒。
配送日期不用于 pickup 告警。缺少字段会作为查询错误处理，不能直接记为“无货”。
