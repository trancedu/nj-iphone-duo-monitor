# 手动重建六个 Checkout 会话

双击项目根目录的 `rebuild-checkout.command`，或在终端运行：

```sh
cd /Users/trance/coding/iPhoneDuo
./rebuild-checkout.command
```

这是手动入口，不会定时执行。与清锁脚本的“健康页面保持不动”不同，此入口会依次让配置中的每个 Safari Profile 回到购物车，确认恰好一台对应商品，然后重新进入 Checkout、选择 I’ll pick it up、设置并回读邮编 07094。每个窗口验证就绪后才算成功；六个窗口串行，不关闭窗口、不创建重复标签，不添加商品，不选择门店时间，不点击最终 Apple Pay 按钮。

执行期间暂停库存接收，结束后恢复接收器。如果已有请求占锁，脚本会拒绝执行，避免打断你操作；请先完成该请求，或明确运行清锁。脚本暂停接收后会再次检查，防止检查期间新请求到来。

结束后输入 `r` 并按回车可以重跑，直接按回车退出。此操作用于重新建立结账会话；不能保证更换 Apple 服务端身份或减少风控，也不等于清除 Safari cookies、缓存或内存。无需定时运行。
